# Documentation du catalogue communautaire

Ce dépôt contient les données publiques, l'interface web et l'automatisation du
catalogue PerfComparator. La documentation est organisée selon ce que vous
voulez accomplir.

## Consulter et comparer

- [Guide utilisateur](guide-utilisateur.md) : rechercher une machine,
  télécharger un rapport, le vérifier et lancer une comparaison locale.
- [Tutoriel complet
  PerfComparator](https://github.com/frchalaoux/perfcomparator/blob/main/docs/tutoriel-catalogue.md) :
  installer l'outil, mesurer une machine, publier puis comparer de A à Z.
- [Données et confidentialité](donnees-et-confidentialite.md) : champs publiés,
  licence CC0, risques de réidentification et limites d'une suppression.

## Contribuer

- [Guide de contribution](../CONTRIBUTING.md) : parcours guidé recommandé,
  contribution manuelle, critères d'acceptation et demandes de retrait.
- [Format
  public](https://github.com/frchalaoux/perfcomparator/blob/main/docs/format-rapport-public.md) :
  contrat détaillé du fichier produit par PerfComparator.

## Maintenir et développer

- [Architecture](architecture.md) : sources de vérité, génération de l'index,
  déploiement statique et modèle de sécurité des workflows.
- [Guide développeur](guide-developpeur.md) : environnement, carte du code,
  parcours de modification, tests et conventions de pull request.
- [Guide de maintenance](maintenance.md) : environnement local, contrôles,
  prévisualisation, ajout, retrait, mise à jour du validateur et déploiement.
- [Dépannage](depannage.md) : erreurs fréquentes dans les pull requests, la
  génération du site et GitHub Pages.

## Dépôts complémentaires

- [PerfComparator](https://github.com/frchalaoux/perfcomparator) contient la
  commande, les benchmarks, l'export public et la comparaison.
- [Catalogue web](https://frchalaoux.github.io/perfcomparator-results/) est
  l'artefact statique construit depuis la branche `main` de ce dépôt.
